A fábrica é um espaço em realidade virtual. Para se mover pelo chão, use teleporte (com mãos ou com controle XR), não ande arrastando o corpo.

Como teletransportar:

Fluxo com as mãos (hand tracking):
- Faça com a mão direita o gesto de ativar teleporte (polegar e indicador estendidos, outros dedos fechados) para abrir a mira.
- Aponte o raio para uma área válida no chão da fábrica.
- Confirme o destino com o gesto de seleção (pinça/fechamento da mão) sobre o alvo válido.
- Para cancelar, abra a mão para sair do modo de teleporte.

Fluxo com controle XR:
- Ative o modo de teleporte pelo comando de locomoção configurado no seu controle.
- Mire o raio em uma área válida no chão.
- Confirme o destino com o comando de seleção do teleporte configurado no controle.
- Para cancelar, use o comando de cancelar teleporte configurado no controle.

Se o raio permanecer vermelho, você está apontando para um obstáculo ou para fora da área permitida. Aponte para o chão livre perto da bancada, da esteira ou do tutor.
