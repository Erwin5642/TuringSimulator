A fábrica é um espaço em realidade virtual. Para se mover pelo chão, use o teleporte do controle XR, não ande arrastando o corpo.

Como teletransportar:
- Aponte o raio de teleporte para uma área válida no chão da fábrica (tapete ou âncora de teleporte).
- Use o analógico / botão de locomoção do controle para confirmar o destino.
- Solte para aparecer no ponto marcado.

Se o raio não acender, você está apontando para um obstáculo ou para fora da área permitida. Aponte para o chão livre perto da bancada, da esteira ou do tutor.

Este é o modo de locomoção previsto no XR Origin da cena. Não é preciso pular nem atravessar mesas.
