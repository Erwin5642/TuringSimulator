Os botões da máquina ficam no painel de controle, não na bancada de blocos.

Começar / Recomeçar:
- Em edição, o botão mostra Começar. Aperta para ligar o programa e ver o robô na esteira.
- Enquanto está rodando, o mesmo botão mostra Recomeçar. Aperta para abortar, resetar a fita e voltar a editar.

Pausar / Rodar:
- Enquanto a reprodução está pedida, o botão mostra Pausar.
- Quando está pausado ou parado, mostra Rodar para continuar.

Use Começar quando o circuito estiver ligado. Use Pausar para olhar célula por célula. Use Recomeçar se o robô travou ou você quer mudar os fios.
