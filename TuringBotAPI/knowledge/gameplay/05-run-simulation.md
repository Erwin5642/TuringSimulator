Na mesma mesa ficam a tomada, a grade para organizar circuitos, as gavetas e os botões de controle da simulação.

Começar / Recomeçar:
- Em edição, o botão mostra Começar. Aperte para ligar o programa e ver o circuito atuando sobre a esteira.
- Enquanto está rodando, o mesmo botão mostra Recomeçar. Aperte para abortar, resetar a fita e voltar à edição.

Pausar / Rodar:
- Enquanto a reprodução está pedida, o botão mostra Pausar.
- Quando está pausado ou parado, mostra Rodar para continuar.

Use Começar quando o circuito estiver ligado. Use Pausar para analisar posição por posição na esteira. Use Recomeçar se quiser resetar tudo e reorganizar os fios.
